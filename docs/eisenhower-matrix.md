# Eisenhower Matrix

Based on the [original matrix](../Eisenhower%20Matrix.pdf).

## Do — MVP

1. Create/select profiles and configure exercise targets and weight increments.
2. Log workouts and save/load them from a JSON file.
3. Display workout history and personal records.
4. Suggest weight increases using the two-workout rep-target rule.

## Schedule — After the MVP

1. Recommended personalized workout routines.
2. Progress graphs.
3. Workout reminders.
4. Weekly workout goal tracking.

## Delegate — Use Existing Python Utilities

For this individual project, these tasks are handled using built-in utilities rather than custom implementations.

1. Use `json` to encode and decode saved workout data.
2. Use `datetime` to handle workout dates.
3. Use built-in file functions to read and write files.
4. Use `os.path` to check file paths and whether files exist.

## Delete — Outside the Project Scope

1. Social features and sharing feeds.
2. AI exercise-form analysis.
3. Wearable-device integration.
4. Nutrition and calorie tracking.
